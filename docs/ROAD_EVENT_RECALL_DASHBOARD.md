# 道の駅イベント・独立公式告知との照合

**初回の自動照合を待っています。**

次の「道の駅イベント情報（全国・地域別）」Actionsが正常終了すると、全国「道の駅」連絡会の公式告知と、既存の地域9サイトの公式お知らせを公開イベントと照合して更新されます。

**ご注意**：URLや見出しが一致しないことは、収集漏れが確定したことを意味しません。公式本文の開催日・駅構内会場・同一イベントかどうかの確認が必要です。

人が確認した標本だけを `data/road_event_recall_reviews.json` に記録した場合に限り、**その標本内**の発見率を計算します。全国のイベント網羅率ではありません。
