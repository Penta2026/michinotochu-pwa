# 道の途中。 現行アプリ仕様書
対象: PWA Ver1.0.8 / 公開DB Ver2.8.20
基準日: 2026-10-05

## 1. アプリ概要
「道の途中。」は、ツーリング・ドライブの行き先を決めたり、
寄り道候補を探したり、走り出すきっかけを作るための支援アプリ。

対応:
- PC
- Android
- iPhone

提供方式:
- GitHub Pages
- PWA
- インストール不要でもブラウザ利用可能
- PWAとしてホーム画面 / デスクトップへ追加可能

## 2. メイン機能
### 道の駅すごろく
- スタート地点を設定。
- 最大直線距離を指定。
- 目標総走行距離を指定。
- 立ち寄る道の駅数を指定、またはランダム。
- ミッションあり / なし。
- 道の駅をつないだ遊び型ツーリングを生成。

### 行先ガチャ
- 目的地までの目安直線距離を指定。
- 距離許容幅を指定。
- 雰囲気を選択。
  - なんでも
  - 海
  - 山
  - 田舎
  - 市街地
  - ランドマーク
- 条件から目的地をランダム抽出。

### 乗り継ぎガチャ
- 現在地点 / 指定地点を起点に次の移動先を生成。
- 移動距離指定。
- 北 / 東 / 南 / 西など方向指定。
- 連続して行き先をつなぐ遊び方を想定。

### 季節を走る
- 今の季節自動選択、または春夏秋冬を指定。
- 最大直線距離を指定。
- 季節向け候補スポットを表示。

### ここからどこ行く？
- 指定地点から一定距離先の候補を検索。
- 対象:
  - すべて
  - 道の駅
  - 定番スポット
  - 寄り道スポット

### 気になる場所
- 都道府県、スポット区分、カテゴリから候補表示。
- 登録スポットを眺めて次の行き先を探す用途。

### お気に入りのルート
- 生成・保存したルートを端末内へ保存。
- 最大20件。
- 選択削除対応。

## 5. 地点検索・ナビゲーション方針
### 登録済み定番 / 寄り道
名称が明確なスポットは名称検索を正とする。
座標は主として距離計算・候補抽出用。

例:
`広島県 マツダミュージアム`

### 道の駅
道の駅名称を使った検索を優先。

### 手入力 / 任意地点
ユーザーが直接入力・指定した緯度経度は、その座標を正として利用。
名称検索へ勝手に置き換えない。

### 道・曖昧な地点
スポット属性により座標利用または検索語を使い分ける。

## 6. Googleマップ連携
### マップで確認
目的地単体をGoogleマップ検索で開く。
名称検索対象は名称、座標指定対象は座標を利用。

### 周辺グルメ
目的地周辺の
- 飲食店
- カフェ
- ラーメン
等をGoogleマップ検索で開く。

### バイク向けルート
#### 125cc以下
Google Maps Directions URLを利用。
`travelmode=driving` に加えて、
高速道路・有料道路を避ける指定を付与。

※ Googleマップ自体に正式な「125cc二輪専用ルーティング」があるわけではないため、
完全な原付専用経路保証ではない。
自動車専用道路等は実走前の確認が必要。

#### 250cc以上
Google Maps Directions URLの通常drivingルートを利用。

## 8. PWA更新機構
### 公開版情報
`data/version.json`

現行:
- appVersion: 1.0.8
- dbVersion: 2.8.20

### 起動時
- PWA本体とDBを確認。
- version.jsonはno-storeで取得。
- 更新がなければそのまま起動。
- 更新確認に失敗しても現行版で利用可能。

### タイムアウト
- 通常ネットワーク: 約5秒
- Service Worker更新: 約4秒
- 起動安全解放: 約6.5秒
- DB本体取得: 約12秒

### DBキャッシュ
Cache Storageの `michino-db` を利用。
DB更新成功後に新データへ差し替え。
失敗時は旧DBを保持。

### Shell cache
現行:
`michino-shell-v1.0.8`

Service Worker activate時に旧 `michino-shell-*` を削除。

## 9. 保存データ
利用者固有データは主に端末側へ保存。
DB差し替えでは消さない方針。

対象例:
- お気に入り
- 保存した行先
- お気に入りのルート
- 利用者設定

ブラウザのサイトデータ削除等では消える可能性がある。
