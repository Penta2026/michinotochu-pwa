# 全国1,234駅・公式イベント巡回台帳

更新日: 2026-10-15

> この台帳は **すべての駅を管理対象にしたもの**です。 **すべての駅の公式サイトを実際に見に行った**という意味ではありません。
> 「現在の登録イベント0件」「個別収集先なし」を **イベントが存在しない**と判断しません。

## 駅単位の進捗

| 指標 | 駅数 |
|---|---:|
| アプリに登録済みの駅 | 1234 |

| 新型エンジン＋既存記事の確認設定 | 30 |

| 検証済み『開催イベントなし』 | 0（未判定） |

## 次の一手

1. 各駅の実際の公式サイトURLを照合し、確定URLだけ駅IDへ結び付ける。
2. 公式サイトが分かった駅をローテーション巡回して『アクセス成功・候補検出・日時会場未確認・イベント確定・取得失敗』を記録。
3. 公開には既存の厳格なイベント検証（公式URL、開催日、駅構内会場、中止判定）を使用。
4. 1,234駅すべての最終巡回日・URL不足を記録した後、毎週の巡回完了率を算出。

## 未設定駅について

全駅の状態一覧は `data/station_coverage_registry.json` を参照。収集ルートを持たない駅も除外せず、駅ID単位で管理する。
