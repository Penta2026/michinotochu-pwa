# 道の駅イベント・取りこぼし監視ダッシュボード

**初回の自動監査を待っています。**

このページは、GitHub Actionsの「道の駅イベント情報（全国・地域別）」が次回正常終了すると、`scripts/road_event_gap_monitor.py` によって毎日自動更新されます。

監視対象はアプリ内の道の駅マスタ **1,234駅（2026-10-04版）**、各駅への個別公式収集先、全国・地域別の公式情報源、未採用の記事候補、取得失敗や再確認待ち情報です。

現状の公開イベント情報と累計47県の実績は変更しません。

**注意:** 個別公式収集先がない駅も、地域連絡会などを通じて収集できる場合があります。従って「個別収集先なし」は「イベント未収集」を意味しません。
