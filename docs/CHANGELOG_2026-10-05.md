# 道の途中。 PWA 更新履歴

この文書は、2026-10-05時点までの会話・作業履歴と現行リポジトリ内容をもとに、
確認できている主な更新をまとめたもの。
途中版の全コミットを完全に列挙するものではなく、機能上重要な節目を記録する。

## PWA 1.0.0
- PC版を母体に、iPhoneで利用できるPWA方式を採用。
- App Store / Macを必要としないGitHub Pages公開方式。
- `manifest.webmanifest`、Service Worker、PWAアイコンを追加。
- DBを `data/app_data.js` として同梱。
- `data/version.json` を使ったDB更新確認を導入。
- iPhone Safariの「ホーム画面に追加」で利用可能にした。

## PWA 1.0.4 付近
- 起動後のバックグラウンド更新処理により、
  「道の駅すごろく」を押した直後などにタイトルへ戻る場合がある問題を確認。
- 原因は、画面遷移後でも更新確認側から `location.reload()` が走る可能性があったこと。

## PWA 1.0.5
- 起動時にPWA本体とDBの更新確認を先に行うスタートアップゲートを追加。
- 更新確認完了前の操作を抑制。
- 更新が存在する場合のみ再読み込みする方針へ変更。
- 起動後に突然リロードされる挙動を抑制。

## PWA 1.0.6
- 「🗺 マップで確認」を、ルートではなく目的地確認用へ整理。
- 「🍜 周辺グルメを検索」を追加。
- バイク向けルートボタンを追加。
  - 🛵 125cc以下
  - 🏍 250cc以上
- JavaScript / CSS / PWA関連のキャッシュバスターを更新。

## PWA 1.0.7
- 更新確認が長時間「更新中 / 確認中」のままになる対策を実施。
- 通信タイムアウト: 約5秒。
- Service Worker更新待ち: 約4秒。
- 起動ゲート安全解放: 約6.5秒。
- DB取得時は約12秒を上限とし、失敗時も現行版で起動可能にした。

## PWA 1.0.8
### ナビゲーション・地点検索
- 定番スポット / 寄り道スポットは、名称が明確な場所では名称検索を優先。
- `spot_overrides.js` を `index.html` から読み込むよう修正。
- Googleマップの「マップで確認」も、名称検索対象では座標固定ではなく名称検索を使用。
- 周辺グルメ検索も名称検索優先ロジックへ変更。
- 手入力や座標指定の任意地点は、座標を正として扱う設計を維持。

### マツダミュージアム補正
- 生成DB側の座標不整合を個別補正。
- 名称検索:
  `広島県 マツダミュージアム`
- 補正座標:
  緯度 34.378020 / 経度 132.502520
- 生成済み `app_data.js` を直接編集せず、overrideレイヤで補正。

### インストール案内
- `install.html` を追加。
- PC / Android / iPhone のインストール説明画像を掲載。
- 各画像をPNG保存できる導線を追加。
- 本体トップに「📱 インストール方法」ボタンを追加。
- PWAとしてstandalone起動している場合は、インストール方法ボタンを非表示。
  - `display-mode: standalone`
  - iOS `navigator.standalone`
  を利用。
