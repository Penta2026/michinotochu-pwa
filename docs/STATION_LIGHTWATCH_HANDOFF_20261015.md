# 道の途中。 全国イベント軽量巡回 Phase 1 引継ぎ（2026-10-15）

## 目的
全国1,234駅のうち公式情報源を検証できた駅を安全に軽量監視し、更新を検知する。既存の公式イベント収集・品質審査は変更しない。

## 導入箇所
- scripts/station_lightwatch.py
- .github/workflows/road-events.yml: 既存の日次イベント収集ジョブ内に軽量監視ステップを追加
- 出力（実行後）：data/station_lightwatch_report.json, data/station_lightwatch_state.json

## 現状の仕様
- 登録駅1,234件は station_coverage_registry.json から読み込む。
- 全駅7日周期の対象割り振りを計算するが、サイト取得は station_event_discovery_sources.json の検証済み・有効な一覧URLのみ。
- 日次ワークフローは --fetch --daily-verified --max-requests 40 で実行。
- ETag/Last-Modified と本文 SHA-256 を使い前回からの変更を判別する。
- 同一ホストへの最低待機2秒、各応答最大512KiB、10秒タイムアウト。
- ページ差分は「新着イベント」ではない。自動でイベント掲載しない。
- 未検証の公式サイト候補にはアクセスしない。
- 日次実行の成功とイベント網羅率は別問題。

## 問題と次工程
- 現在の駅別収集対象は約39駅。大半の1,234駅は未設定。実サイトの登録・所有者の検証を増やす必要がある。
- 広島県・道の駅「湖畔の里福富」の11月3日レトロカーフェスタは、未収集の回帰テスト対象。
- 公式駅サイト、お知らせ一覧、イベント個別記事の取得ルールを登録し、開催日・会場・キャンセル等を検証して採用する。
- 今回追加した監視は「HTML差分検出」であり、イベント記事の新規自動解析と採用は未実装。
- 安全性・掲載率の評価と、巡回時間・エラー率を定期確認して段階的に拡大する。

## 点検
GitHub Actions → 道の駅イベント情報（全国・地域別） → 直近Run。
軽量監視結果は data/station_lightwatch_report.json。
未取得・エラー・未検証は「イベントなし」として扱わない。
